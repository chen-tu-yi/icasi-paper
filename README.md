# 2026 IEEE 12th International Conference on Applied System Innovation (ICASI)

This research is developed based on a **real-world industrial case study** from a collaborating manufacturing company. The paper proposes an applied system framework aimed at solving practical bottlenecks and optimization challenges in industry production lines.
