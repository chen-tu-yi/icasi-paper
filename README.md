# 2026 IEEE 12th International Conference on Applied System Innovation (ICASI)

This repository contains the paper submitted to **ICASI 2026** and other certifications.

## Overview

This research is developed based on a **real-world industrial case study** from a collaborating manufacturing company. The paper proposes an applied system framework aimed at solving practical bottlenecks and optimization challenges in industry production lines.

*   **Conference:** IEEE 12th International Conference on Applied System Innovation (ICASI 2026)
*   **Location:** Kyoto, Japan
*   **Date:** April 14–17, 2026
*   **Paper no.:** J260289
*   **Paper title:** An Intelligent Decision Support System for Material Planning and Production Process Optimization in Smart Factories
*   **Author(s):** CHEN,TU YI; CHEN, YI HUNG; LU, PIN-YEN; CHIU, SHENG-MIN
